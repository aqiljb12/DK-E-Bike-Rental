DK E-BIKE RENTAL DEMO

Cara guna:
1. Buka index.html di browser, atau deploy folder ini ke Netlify/Vercel/static hosting.
2. Pilih cawangan Senai/Kulai.
3. Tab Rental > tekan "Scan Demo" untuk simulasi scan barcode.
4. Pilih 30/60/90 minit dan mula rental.
5. Countdown akan berjalan. Tekan Tamat untuk masukkan transaksi ke Report.
6. Tab Bikes untuk tambah basikal atau tukar status maintenance.
7. Tab Service untuk rekod servis.

Nota:
- Ini DEMO front-end sahaja.
- Data disimpan dalam localStorage per device/browser.
- Belum ada login sebenar, database cloud, owner remote live sync, atau camera barcode production.
- Untuk production, cadangan next step: Supabase + auth + multi-branch + audit trail + kamera barcode/QR + role Owner/Staff.
